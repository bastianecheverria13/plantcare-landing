# 🚀 PlantCare React - Quick Start

## Paso 1: Preparar archivos

1. Copia todo el contenido de `index.css` (del documento HTML/CSS original) a:
   ```
   src/styles/index.css
   ```

2. Copia las imágenes a la carpeta `public/`:
   - `logo_plantcare_blanco.png`
   - `logo_plantcare_verde.png` (renombra el que tiene -removebg-preview)
   - `planta_presentacion.png`

## Paso 2: Instalar

```bash
npm install
```

## Paso 3: Ejecutar

```bash
npm run dev
```

## Paso 4: Abrir navegador

Abre: http://localhost:3000

## ✅ Checklist

- [ ] CSS copiado a `src/styles/index.css`
- [ ] Imágenes en carpeta `public/`
- [ ] `npm install` ejecutado
- [ ] Servidor corriendo con `npm run dev`
- [ ] Página funciona en el navegador
